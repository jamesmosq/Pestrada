  EJERCICIO 1 — EL DATO VIAJA POR LA URL (metodo GET)
  Archivo: ejercicio1/formulario.html
════════════════════════════════════════════════════════════════════════════════

CONCEPTO NUEVO: metodo GET
  Cuando un formulario usa method="GET", los datos viajan visibles
  en la URL del navegador:
    http://...recibir.php?nombre=Carlos&ciudad=Medellin

  Util para: busquedas, filtros, consultas
  No usar para: contrasenas, datos sensibles

OBJETIVO
  Crear un formulario de consulta de clima que envia ciudad por GET.
  No hay PHP en este ejercicio, solo HTML puro con Bootstrap.

CONCEPTO NUEVO: metodo POST y superglobal $_POST
  Con method="POST" los datos NO aparecen en la URL.
  Viajan en el cuerpo de la peticion HTTP (invisible para el usuario).
  PHP los recibe en el array superglobal $_POST.

  Acceder a un campo:  $_POST['nombre_del_campo']
  El nombre del campo en PHP debe coincidir exactamente con el
  atributo name="" del input en el formulario.

OBJETIVO
  Formulario de inscripcion a un evento. El archivo recibir.php
  muestra en pantalla los datos que llegan del formulario.

  EJERCICIO 3 — PHP VALIDA LOS DATOS
  Archivos: ejercicio3/formulario.php  |  ejercicio3/recibir.php
════════════════════════════════════════════════════════════════════════════════

CONCEPTO NUEVO: validacion del lado del servidor
  El navegador puede validar con required, type="email", etc.
  Pero esa validacion se puede desactivar o evadir.
  PHP debe validar siempre, independientemente de lo que haga el navegador.

  Funciones utiles de PHP para validar:
    empty($valor)              → true si esta vacio o es null
    trim($valor)               → elimina espacios al inicio y al final
    strlen($valor)             → longitud del string
    filter_var($v, FILTER_*)   → valida emails, URLs, numeros, etc.
    is_numeric($valor)         → true si es un numero

OBJETIVO
  Formulario de registro de producto. PHP valida cada campo y
  devuelve mensajes de error especificos por campo.

─── ejercicio3/recibir.php ─────────────────────────────────────────────────────

<?php
session_start();

// Si no llego por POST, redirigir al formulario
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    header('Location: formulario.php');
    exit;
}

// ── Capturar y limpiar datos ────────────────────────────────────────────────
$nombre      = trim($_POST['nombre']      ?? '');
$precio      = trim($_POST['precio']      ?? '');
$stock       = trim($_POST['stock']       ?? '');
$descripcion = trim($_POST['descripcion'] ?? '');

// ── Validar cada campo ───────────────────────────────────────────────────────
$errores = [];

if (empty($nombre)) {
    $errores[] = 'El nombre del producto es obligatorio.';
} elseif (strlen($nombre) < 3) {
    $errores[] = 'El nombre debe tener al menos 3 caracteres.';
}

if (empty($precio)) {
    $errores[] = 'El precio es obligatorio.';
} elseif (!is_numeric($precio)) {
    $errores[] = 'El precio debe ser un numero.';
} elseif ((float)$precio <= 0) {
    $errores[] = 'El precio debe ser mayor a cero.';
}

if ($stock === '') {
    $errores[] = 'El stock es obligatorio.';
} elseif (!is_numeric($stock) || (int)$stock < 0) {
    $errores[] = 'El stock debe ser un numero igual o mayor a cero.';
}

if (empty($descripcion)) {
    $errores[] = 'La descripcion es obligatoria.';
} elseif (strlen($descripcion) < 10) {
    $errores[] = 'La descripcion debe tener al menos 10 caracteres.';
}

// ── Si hay errores: guardar en sesion y regresar al formulario ───────────────
if (!empty($errores)) {
    // Guardar errores para mostrarlos en el formulario
    $_SESSION['errores'] = $errores;
    // Guardar los datos para no perder lo que el usuario escribio
    $_SESSION['datos'] = [
        'nombre'      => $nombre,
        'precio'      => $precio,
        'stock'       => $stock,
        'descripcion' => $descripcion,
    ];
    header('Location: formulario.php');
    exit;
}

// ── Si todo es valido: mostrar resumen ───────────────────────────────────────
?>
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Producto validado</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"
          rel="stylesheet">
</head>
<body class="bg-light">

<div class="container mt-5">
    <div class="row justify-content-center">
        <div class="col-md-6">
            <div class="alert alert-success">
                <h5>Datos validos. El producto seria guardado:</h5>
            </div>
            <div class="card shadow-sm">
                <div class="card-body">
                    <table class="table">
                        <tr><th>Nombre</th>
                            <td><?php echo htmlspecialchars($nombre); ?></td></tr>
                        <tr><th>Precio</th>
                            <td>$ <?php echo number_format((float)$precio, 0, ',', '.'); ?></td></tr>
                        <tr><th>Stock</th>
                            <td><?php echo (int)$stock; ?> unidades</td></tr>
                        <tr><th>Descripcion</th>
                            <td><?php echo htmlspecialchars($descripcion); ?></td></tr>
                    </table>
                    <a href="formulario.php" class="btn btn-warning text-dark">
                        Registrar otro
                    </a>
                </div>
            </div>
        </div>
    </div>
</div>

</body>
</html>

  EJERCICIO 4 — GUARDAR EN MYSQL POR PRIMERA VEZ
  Archivos: ejercicio4/formulario.php  |  ejercicio4/guardar.php

CONCEPTO NUEVO: PDO — conectarse y guardar en la base de datos
  PDO (PHP Data Objects) es la forma moderna de conectarse a MySQL.

  Tres pasos para guardar un dato:
    1. Conectar:   $pdo = new PDO($dsn, $usuario, $clave)
    2. Preparar:   $stmt = $pdo->prepare("INSERT INTO ... VALUES (?)")
    3. Ejecutar:   $stmt->execute([$valor])

  ?Por que prepare() y no escribir el SQL directo?
    Si se escribe: "INSERT INTO productos WHERE nombre = '$nombre'"
    y el usuario escribe: ' OR '1'='1   como nombre
    el SQL resultante se convierte en un ataque.
    prepare() evita completamente este problema.

OBJETIVO
  El formulario del Ejercicio 3 ahora guarda el producto en la tabla
  "productos" de la base de datos. Se agrega la conexion PDO.

<?php

    header('Location: index.php');
    exit;

$nombre   = trim($_POST['nombre']   ?? '');
$email    = trim($_POST['email']    ?? '');
$telefono = trim($_POST['telefono'] ?? '');
$mensaje  = trim($_POST['mensaje']  ?? '');

$errores = [];
if (empty($nombre))                          $errores[] = 'El nombre es obligatorio.';
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errores[] = 'El email no es valido.';
if (empty($mensaje))                         $errores[] = 'El mensaje es obligatorio.';

if (!empty($errores)) {
    $_SESSION['errores'] = $errores;
    $_SESSION['datos']   = compact('nombre', 'email', 'telefono', 'mensaje');
    header('Location: crear.php');
    exit;
}

$stmt = $pdo->prepare(
    "INSERT INTO contactos (nombre, email, telefono, mensaje) VALUES (?, ?, ?, ?)"
);
$ok = $stmt->execute([$nombre, $email, $telefono, $mensaje]);

if ($ok) {
    $msg = urlencode("El contacto \"$nombre\" fue guardado.");
    header("Location: index.php?status=creado&msg=$msg");
} else {
    $msg = urlencode('No se pudo guardar el contacto.');
    header("Location: index.php?status=error&msg=$msg");

  ERRORES FRECUENTES EN ESTA SERIE
════════════════════════════════════════════════════════════════════════════════

  ERROR: La pagina redirige en bucle (formulario → recibir → formulario)
  CAUSA: Se accede a recibir.php directamente sin enviar el formulario
  SOLUCION: La verificacion de REQUEST_METHOD al inicio evita esto

  ERROR: El mensaje de SweetAlert2 aparece con caracteres raros
  CAUSA: Se uso echo $mensaje directamente en el JS
  SOLUCION: Usar json_encode: const mensaje = <?php echo json_encode($msg); ?>;

  ERROR: Los datos del formulario se pierden cuando hay error de validacion
  CAUSA: No se guardaron en $_SESSION antes de redirigir
  SOLUCION: Guardar en $_SESSION['datos'] antes del header('Location...')
            y leer con $datos = $_SESSION['datos'] ?? [] en el formulario

  ERROR: SQLSTATE[HY000] [1049] Unknown database
  CAUSA: La base de datos no existe o el nombre esta mal escrito
  SOLUCION: Verificar en phpMyAdmin que "sena_formularios" existe

  ERROR: La alerta de confirmacion aparece pero no envia el formulario
  CAUSA: El boton tiene type="submit" — el form se envia antes de Swal
  SOLUCION: Cambiar a type="button" y llamar form.submit() dentro del .then()
