¿QUE VAMOS A CONSTRUIR?
────────────────────────
Un sistema web de gestion de estudiantes con las siguientes caracteristicas:

  - Arquitectura MVC (Model - View - Controller)
  - Operaciones CRUD completas (Crear, Leer, Actualizar, Eliminar)
  - Alertas modernas con SweetAlert2
  - Iconos con Font Awesome

Al finalizar tendra un proyecto que es la base conceptual exacta de

¿QUE ES MVC?
─────────────
MVC divide el codigo en tres capas con responsabilidades separadas:

  CAPA         ARCHIVO(S)                    HACE...
  ──────────── ─────────────────────────     ─────────────────────────────────
  Model        models/EstudianteModel.php    Consultas SQL. Solo eso.
  View         views/estudiantes/*.php       HTML que ve el usuario. Solo eso.
  Controller   controllers/Estudiante...php  Coordina Model y View. Decide.
  ──────────── ─────────────────────────     ─────────────────────────────────

  Regla de oro:
    - El Model NUNCA genera HTML
    - La View NUNCA ejecuta SQL
    - El Controller NUNCA mezcla SQL con HTML

  Flujo de una peticion:
    Navegador → index.php (Router) → Controller → Model → Controller → View

  PASO 4 — CONEXION A LA BASE DE DATOS
  Archivo: config/Database.php
════════════════════════════════════════════════════════════════════════════════

Conceptos nuevos en este archivo:

  PDO (PHP Data Objects)
    Interfaz de PHP para conectarse a bases de datos. A diferencia de mysqli,
    PDO funciona con MySQL, PostgreSQL, SQLite y otros motores. Es el estandar
    que usa Laravel internamente.

  Patron Singleton
    Garantiza que en toda la ejecucion del programa exista UNA sola conexion
    a la base de datos. Si 10 archivos llaman a Database::getConnection(),
    todos obtienen la misma conexion, no se abren 10 conexiones distintas.

  Metodo estatico
    Se llama con :: en lugar de ->. No requiere crear un objeto primero.
    Ejemplo: Database::getConnection() en lugar de $db = new Database(); $db->getConnection();

─── config/Database.php ────────────────────────────────────────────────────────

<?php

class Database
{
    // Datos de conexion
    private static string $host    = 'localhost';
    private static string $db      = 'sena_mvc';
    private static string $user    = 'root';
    private static string $pass    = '';
    private static string $charset = 'utf8';

    // Guarda la unica instancia de conexion (Singleton)
    private static ?PDO $connection = null;

    // Constructor privado: impide hacer "new Database()" desde afuera
    private function __construct() {}

    // Unico punto de acceso a la conexion
    public static function getConnection(): PDO
    {
        if (self::$connection === null) {

            $dsn = "mysql:host=" . self::$host
                 . ";dbname="   . self::$db
                 . ";charset="  . self::$charset;

            $opciones = [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            ];

            self::$connection = new PDO($dsn, self::$user, self::$pass, $opciones);
        }

        return self::$connection;
    }
}

════════════════════════════════════════════════════════════════════════════════
  PASO 5 — MODEL
  Archivo: models/EstudianteModel.php
════════════════════════════════════════════════════════════════════════════════

El Model es la unica capa que habla con la base de datos.
Cada metodo corresponde a una operacion: obtener todos, obtener uno,
crear, actualizar o eliminar.

Concepto clave — Consultas preparadas (Prepared Statements):
  En lugar de construir el SQL concatenando variables:
    MALO:  "SELECT * FROM estudiantes WHERE id = $id"   <- SQL Injection
    BIEN:  "SELECT * FROM estudiantes WHERE id = ?"     <- Seguro

  El signo ? es un marcador que PDO reemplaza de forma segura.
  Tambien se pueden usar parametros con nombre: :id, :nombre, :email

─── models/EstudianteModel.php ─────────────────────────────────────────────────

<?php

require_once __DIR__ . '/../config/Database.php';

class EstudianteModel
{
    private PDO $db;

    public function __construct()
    {
        $this->db = Database::getConnection();
    }

    // ── Obtener todos los estudiantes ────────────────────────────────────────
    public function obtenerTodos(): array
    {
        $stmt = $this->db->query("SELECT * FROM estudiantes ORDER BY id DESC");
        return $stmt->fetchAll();
    }

    // ── Obtener un estudiante por su ID ──────────────────────────────────────
    public function obtenerPorId(int $id): array|false
    {
        $stmt = $this->db->prepare("SELECT * FROM estudiantes WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->fetch();
    }

    // ── Insertar nuevo estudiante ────────────────────────────────────────────
    public function crear(array $datos): bool
    {
        $stmt = $this->db->prepare(
            "INSERT INTO estudiantes (nombre, email, ficha)
             VALUES (:nombre, :email, :ficha)"
        );
        try {
            return $stmt->execute([
                ':nombre' => $datos['nombre'],
                ':email'  => $datos['email'],
                ':ficha'  => $datos['ficha'],
            ]);
        } catch (PDOException $e) {
            return $this->manejarDuplicado($e);
        }
    }

    // ── Actualizar estudiante existente ──────────────────────────────────────
    public function actualizar(int $id, array $datos): bool
    {
        $stmt = $this->db->prepare(
            "UPDATE estudiantes
             SET nombre = :nombre,
                 email  = :email,
                 ficha  = :ficha
             WHERE id = :id"
        );
        try {
            return $stmt->execute([
                ':nombre' => $datos['nombre'],
                ':email'  => $datos['email'],
                ':ficha'  => $datos['ficha'],
                ':id'     => $id,
            ]);
        } catch (PDOException $e) {
            return $this->manejarDuplicado($e);
        }
    }

    // ── Eliminar estudiante ──────────────────────────────────────────────────
    public function eliminar(int $id): bool
    {
        $stmt = $this->db->prepare("DELETE FROM estudiantes WHERE id = ?");
        return $stmt->execute([$id]);
    }

    // Con ERRMODE_EXCEPTION, un email repetido lanza una excepcion (codigo 23000)
    // en lugar de devolver false. La convertimos en false para que el
    // Controller muestre el mensaje con SweetAlert2. Otros errores se relanzan.
    private function manejarDuplicado(PDOException $e): bool
    {
        if ($e->getCode() === '23000') {
            return false;
        }
        throw $e;
    }
}

════════════════════════════════════════════════════════════════════════════════
  PASO 6 — CONTROLLER
  Archivo: controllers/EstudianteController.php
════════════════════════════════════════════════════════════════════════════════

El Controller recibe la accion del Router, valida los datos de entrada,
llama al Model para operar con la BD, y decide que View mostrar.

Metodos publicos (acciones disponibles):
  index()      - Mostrar lista de estudiantes
  crear()      - Mostrar formulario de creacion (GET)
  guardar()    - Procesar formulario de creacion (POST)
  editar()     - Mostrar formulario de edicion precargado (GET)
  actualizar() - Procesar formulario de edicion (POST)
  eliminar()   - Eliminar y redirigir (solo por POST)

Metodos privados (auxiliares internos):
  cargarVista() - Incluye el archivo de View con sus variables (y el token $csrf)
  redirigir()   - Centraliza todas las redirecciones
  csrfToken()   - Genera, una vez por sesion, el token de seguridad
  csrfValido()  - Comprueba que el formulario envio ese mismo token

Concepto clave — Las acciones que modifican datos van por POST:
  guardar(), actualizar() y eliminar() rechazan cualquier peticion que no sea POST.
  Si eliminar funcionara con un enlace (GET), bastaria con que alguien abriera
  index.php?action=eliminar&id=3 (o que el navegador precargara ese enlace)
  para borrar un registro.

Concepto clave — Token CSRF:
  CSRF es un ataque en el que otra pagina envia un formulario a nuestro sistema
  aprovechando que el usuario tiene la sesion abierta. Para evitarlo:
    1. El Controller genera un codigo aleatorio y lo guarda en $_SESSION.
    2. Cada formulario lo envia en un <input type="hidden" name="csrf_token">.
    3. Antes de guardar, actualizar o eliminar, el Controller compara ambos con
       hash_equals(). Si no coinciden, rechaza la peticion.
  La otra pagina no puede leer nuestro token, asi que no puede falsificarlo.
  En Laravel esto se escribe con una sola linea en el formulario: @csrf

Concepto — Email repetido:
  La columna email es UNIQUE. Con PDO::ERRMODE_EXCEPTION, insertar un email
  repetido lanza una PDOException (codigo 23000). El Model la convierte en
  false para que el Controller muestre el mensaje con SweetAlert2 en lugar de
  un "Fatal error".

─── controllers/EstudianteController.php ───────────────────────────────────────

<?php

require_once __DIR__ . '/../models/EstudianteModel.php';

class EstudianteController
{
    private EstudianteModel $model;

    public function __construct()
    {
        $this->model = new EstudianteModel();
    }

    // ── Listar estudiantes ───────────────────────────────────────────────────
    public function index(): void
    {
        $status      = $_GET['status']  ?? '';
        $mensaje     = $_GET['mensaje'] ?? '';
        $estudiantes = $this->model->obtenerTodos();

        $this->cargarVista('estudiantes/index', compact('estudiantes', 'status', 'mensaje'));
    }

    // ── Mostrar formulario de creacion ───────────────────────────────────────
    public function crear(): void
    {
        $status  = $_GET['status']  ?? '';
        $mensaje = $_GET['mensaje'] ?? '';

        $this->cargarVista('estudiantes/crear', compact('status', 'mensaje'));
    }

    // ── Guardar nuevo estudiante (POST) ──────────────────────────────────────
    public function guardar(): void
    {
        if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
            $this->redirigir('index');
            return;
        }

        if (!$this->csrfValido()) {
            $this->redirigir('crear', 'error',
                urlencode('La sesion expiro. Recarga la pagina e intenta de nuevo.'));
            return;
        }

        $nombre = trim($_POST['nombre'] ?? '');
        $email  = trim($_POST['email']  ?? '');
        $ficha  = trim($_POST['ficha']  ?? '');

        if (empty($nombre) || empty($email)) {
            $this->redirigir('crear', 'error',
                urlencode('El nombre y el email son obligatorios.'));
            return;
        }

        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            $this->redirigir('crear', 'error',
                urlencode('El formato del email no es valido.'));
            return;
        }

        $ok = $this->model->crear([
            'nombre' => $nombre,
            'email'  => $email,
            'ficha'  => $ficha,
        ]);

        if ($ok) {
            $this->redirigir('index', 'creado',
                urlencode("El estudiante \"$nombre\" fue registrado correctamente."));
        } else {
            $this->redirigir('crear', 'error',
                urlencode('No se pudo guardar. El email ya puede estar en uso.'));
        }
    }

    // ── Mostrar formulario de edicion ────────────────────────────────────────
    public function editar(): void
    {
        $id = intval($_GET['id'] ?? 0);

        if ($id <= 0) {
            $this->redirigir('index', 'error', urlencode('ID no valido.'));
            return;
        }

        $estudiante = $this->model->obtenerPorId($id);

        if (!$estudiante) {
            $this->redirigir('index', 'error', urlencode('Estudiante no encontrado.'));
            return;
        }

        $status  = $_GET['status']  ?? '';
        $mensaje = $_GET['mensaje'] ?? '';

        $this->cargarVista('estudiantes/editar',
            compact('estudiante', 'status', 'mensaje'));
    }

    // ── Actualizar estudiante (POST) ─────────────────────────────────────────
    public function actualizar(): void
    {
        if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
            $this->redirigir('index');
            return;
        }

        $id     = intval($_POST['id']     ?? 0);
        $nombre = trim($_POST['nombre']   ?? '');
        $email  = trim($_POST['email']    ?? '');
        $ficha  = trim($_POST['ficha']    ?? '');

        if (!$this->csrfValido()) {
            $this->redirigir('editar', 'error',
                urlencode('La sesion expiro. Recarga la pagina e intenta de nuevo.'), $id);
            return;
        }

        if ($id <= 0 || empty($nombre) || empty($email)) {
            $this->redirigir('editar', 'error',
                urlencode('Datos incompletos.'), $id);
            return;
        }

        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            $this->redirigir('editar', 'error',
                urlencode('El formato del email no es valido.'), $id);
            return;
        }

        $ok = $this->model->actualizar($id, [
            'nombre' => $nombre,
            'email'  => $email,
            'ficha'  => $ficha,
        ]);

        if ($ok) {
            $this->redirigir('index', 'editado',
                urlencode("Los datos de \"$nombre\" fueron actualizados."));
        } else {
            $this->redirigir('editar', 'error',
                urlencode('No se pudo actualizar. El email puede estar en uso.'), $id);
        }
    }

    // ── Eliminar estudiante (POST) ───────────────────────────────────────────
    // Se elimina por POST, nunca por GET: un simple enlace no debe poder borrar datos.
    public function eliminar(): void
    {
        if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
            $this->redirigir('index');
            return;
        }

        if (!$this->csrfValido()) {
            $this->redirigir('index', 'error',
                urlencode('La sesion expiro. Recarga la pagina e intenta de nuevo.'));
            return;
        }

        $id = intval($_POST['id'] ?? 0);

        if ($id <= 0) {
            $this->redirigir('index', 'error', urlencode('ID no valido.'));
            return;
        }

        $est = $this->model->obtenerPorId($id);

        if (!$est) {
            $this->redirigir('index', 'error', urlencode('Estudiante no encontrado.'));
            return;
        }

        $ok = $this->model->eliminar($id);

        if ($ok) {
            $this->redirigir('index', 'eliminado',
                urlencode("\"$est[nombre]\" fue eliminado del sistema."));
        } else {
            $this->redirigir('index', 'error',
                urlencode('No se pudo eliminar el registro.'));
        }
    }
    // ════════════════════════════════════════════════════════════════════════
    // METODOS PRIVADOS AUXILIARES
    // ════════════════════════════════════════════════════════════════════════

    // Carga el archivo de vista y le inyecta variables mediante extract()
    // Todas las vistas reciben $csrf para incluirlo en sus formularios.
    private function cargarVista(string $vista, array $datos = []): void
    {
        $datos['csrf'] = $this->csrfToken();
        extract($datos);
        require __DIR__ . "/../views/{$vista}.php";
    }

    // Construye y ejecuta una redireccion hacia el router
    private function redirigir(
        string $action,
        string $status  = '',
        string $mensaje = '',
        int    $id      = 0
    ): void {
        $url = "index.php?action={$action}";
        if ($status)  $url .= "&status={$status}";
        if ($mensaje) $url .= "&mensaje={$mensaje}";
        if ($id > 0)  $url .= "&id={$id}";
        header("Location: {$url}");
        exit;
    }

    // Genera (una sola vez por sesion) el token CSRF
    private function csrfToken(): string
    {
        if (empty($_SESSION['csrf_token'])) {
            $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
        }
        return $_SESSION['csrf_token'];
    }

    // Comprueba que el formulario envio el mismo token que guarda la sesion
    private function csrfValido(): bool
    {
        $token = $_POST['csrf_token'] ?? '';
        return isset($_SESSION['csrf_token'])
            && hash_equals($_SESSION['csrf_token'], $token);
    }
}

    - filter_var() con FILTER_VALIDATE_EMAIL es validacion nativa de PHP
    - Siempre se llama exit despues de header('Location...') para detener
      la ejecucion del script inmediatamente

════════════════════════════════════════════════════════════════════════════════
  PASO 7 — ROUTER
  Archivo: index.php (raiz del proyecto)
════════════════════════════════════════════════════════════════════════════════

El Router es el unico archivo al que apunta el navegador.
Lee el parametro ?action= de la URL y llama al metodo correspondiente
del Controller. Todo el trafico pasa por aqui.

Ademas, el Router:
  - Llama a session_start(): la sesion guarda el token CSRF.
  - Define la constante DESDE_ROUTER. Cada View comprueba que exista; si alguien
    abre una View directamente en el navegador (por ejemplo
    views/estudiantes/index.php), la View lo redirige a index.php.
    Sin esto, la pagina se veria sin estilos y llena de "Undefined variable",
    porque las Views solo funcionan cuando el Controller les envia los datos.

  URL de ejemplo:
    http://localhost/mvc-sweetalert/index.php?action=crear
    http://localhost/mvc-sweetalert/index.php?action=editar&id=2

─── index.php ──────────────────────────────────────────────────────────────────

<?php

// Marca que la peticion entro por el router: las vistas lo exigen
define('DESDE_ROUTER', true);

// La sesion guarda el token CSRF (en Laravel esto lo hace @csrf)
session_start();

require_once __DIR__ . '/controllers/EstudianteController.php';

$action = $_GET['action'] ?? 'index';

$controller = new EstudianteController();

// Solo estas acciones son validas (lista blanca de seguridad)
$accionesPermitidas = [
    'index'      => 'index',
    'crear'      => 'crear',
    'guardar'    => 'guardar',
    'editar'     => 'editar',
    'actualizar' => 'actualizar',
    'eliminar'   => 'eliminar',
];

if (array_key_exists($action, $accionesPermitidas)) {
    $metodo = $accionesPermitidas[$action];
    $controller->$metodo();
} else {
    header('Location: index.php?action=index');
    exit;
}

────────────────────────────────────────────────────────────────────────────────

  Por que una lista blanca?
    Sin ella, alguien podria poner ?action=metodoSecreto en la URL e intentar
    ejecutar metodos internos del Controller. La lista blanca garantiza que
    solo se puedan llamar las acciones explicitamente permitidas.

    - ?Que accion se ejecuta si el usuario accede solo a index.php sin parametros?
    - ?Que pasaria si alguien pone ?action=eliminarTodo en la URL?

  RESUMEN DE SWEETALERT2 — PATRONES USADOS EN ESTE PROYECTO
════════════════════════════════════════════════════════════════════════════════

  // 1. Alerta simple con icono
  Swal.fire({
      icon:  'success' | 'error' | 'warning' | 'info' | 'question',
      title: 'Titulo',
      text:  'Mensaje',
  });

  // 2. Alerta con cierre automatico
  Swal.fire({
      icon:              'success',
      title:             'Guardado',
      text:              'Operacion completada',
      timer:             2500,
      timerProgressBar:  true,
      showConfirmButton: false,
  });

  // 3. Alerta de confirmacion (retorna Promesa)
  Swal.fire({
      icon:              'warning',
      title:             'Confirmar',
      text:              'Esta accion no se puede deshacer',
      showCancelButton:  true,
      confirmButtonText: 'Si, continuar',
      cancelButtonText:  'Cancelar',
      confirmButtonColor:'#d9534f',
      cancelButtonColor: '#6c757d',
  }).then((result) => {
      if (result.isConfirmed) {
          // el usuario acepto
      }
  });

  // 4. Inyeccion segura de datos PHP en JavaScript
  const mensaje = <?php echo json_encode($mensaje); ?>;
  //  Correcto: json_encode maneja comillas y caracteres especiales

  //  Incorrecto (puede romper el JS con ciertos textos):
  const mensaje = "<?php echo $mensaje; ?>";


════════════════════════════════════════════════════════════════════════════════
  ERRORES FRECUENTES Y COMO RESOLVERLOS
════════════════════════════════════════════════════════════════════════════════

  ERROR: Failed to open stream: No such file or directory
  CAUSA: El archivo de View no existe en la ruta indicada
  SOLUCION: Verificar que la carpeta views/estudiantes/ existe y que
            index.php, crear.php y editar.php estan dentro de ella

  ERROR: La alerta aparece pero el formulario no se envia
  CAUSA: El boton tiene type="submit" en lugar de type="button"
  SOLUCION: Cambiar a type="button". El envio lo controla JS con form.submit()

  ERROR: Cannot modify header information - headers already sent
  CAUSA: Algo se imprimio antes de header() o de session_start(). Lo mas comun
         es una linea en blanco ANTES de "<?php" en algun archivo (por ejemplo
         en config/Database.php), o un echo de prueba que quedo en el codigo.
  SOLUCION: Revisar que todos los archivos PHP empiecen exactamente con "<?php"
            en la primera linea, sin espacios ni lineas en blanco antes.

  ERROR: Pagina en blanco al guardar
  CAUSA: Falta exit despues del header('Location...')
  SOLUCION: Siempre escribir exit inmediatamente despues de header()

  ERROR: Mensaje con caracteres raros en la alerta
  CAUSA: Se uso echo $mensaje directamente en el JavaScript
  SOLUCION: Usar json_encode(): const mensaje = <?php echo json_encode($mensaje); ?>;

  ERROR: La tabla aparece pero sin estilos (y con "Undefined variable")
  CAUSA: Se abrio una View directamente (views/estudiantes/index.php) en lugar
         de index.php. Pasa mucho con el boton "abrir en el navegador" de
         PhpStorm o VS Code, que abre el archivo que se esta editando.
  SOLUCION: Abrir siempre index.php. Con la proteccion DESDE_ROUTER la View
            redirige sola. Si aun asi no hay estilos, verificar que exista
            assets/css/app.css: la ruta es relativa al index.php raiz.

  ERROR: "La sesion expiro. Recarga la pagina e intenta de nuevo."
  CAUSA: El formulario no envio el token CSRF, o la sesion se cerro.
  SOLUCION: Verificar que el formulario tenga
            <input type="hidden" name="csrf_token" value="..."> y que
            index.php llame a session_start() antes que todo.

  ERROR: Duplicate entry for key 'email'
  CAUSA: Se intento registrar un email que ya existe (columna UNIQUE)
  SOLUCION: El Model atrapa la PDOException (codigo 23000) y devuelve false;
            el Controller muestra "El email puede estar en uso".
            Si aparece como Fatal error, falta el try/catch en el Model.

  GLOSARIO
════════════════════════════════════════════════════════════════════════════════

  MVC          Patron de arquitectura: Model, View, Controller
  PDO          PHP Data Objects — interfaz para conectarse a bases de datos
  Singleton    Patron que garantiza una sola instancia de un objeto
  Prepared     Consulta SQL parametrizada, protegida contra SQL Injection
  Statement
  CRUD         Create, Read, Update, Delete — las 4 operaciones basicas
  XSS          Cross-Site Scripting — ataque que inyecta JS malicioso en HTML
  CSRF         Cross-Site Request Forgery — otra pagina envia formularios a
               nuestro sistema usando la sesion del usuario
  htmlspecialchars  Funcion PHP que escapa caracteres HTML para prevenir XSS
  json_encode  Funcion PHP que convierte datos a formato JSON seguro para JS
  urlencode    Funcion PHP que codifica texto para usarlo en una URL
  trim()       Elimina espacios al inicio y al final de un string
  compact()    Crea un array asociativo a partir de nombres de variables
  extract()    Convierte claves de un array en variables independientes
  filter_var   Funcion PHP para validar y filtrar datos (emails, URLs, etc.)
  Promesa      Objeto JS que representa una operacion que puede completarse
               o fallar en el futuro (SweetAlert2 usa .then() para esto)
